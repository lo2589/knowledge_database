# known_manage — 从对话里把有用的那几句挑出来，变成自己的知识

跟 agent 聊一下午，真正学到的可能就三五句，混在几百句里，过几天就找不到了。这个工具做四件事：

1. **拆**：把对话、文章拆成一句一句。公式、代码、表格、图不会被拆开。
2. **挑**：你一句句往下看，`Y` 留、`X` 扔。拆错了就 `M` 合并、`E` 改。
3. **入库**：留下的句子做成知识卡片。可以一句一张，也可以几句合成一张，自己写标题。每张卡都记得它来自原文哪句话，点一下就能跳回去。
4. **链接**：你自己把卡片连起来，比如"属于""前提是""是…的例子""细化了""矛盾""相关"，关系图里能看到整张网。

为什么连关系要你自己来，不让 AI 自动连：有研究发现，AI 画的知识结构图更清楚，但人记不住；人自己画的更乱，记得反而更牢。挂结构这个动作本身就是学习。

## 能导入什么

| 来源 | 怎么导入 |
|---|---|
| 随手粘贴的文字、Markdown、网页内容 | 「导入 → 粘贴」 |
| Claude Code 的会话 | 「导入 → Claude Code 会话」，直接列出 `~/.claude/projects` 下最近的会话。只取你说的话和它的回答，工具调用、思考过程、系统提示都去掉 |
| ChatGPT 导出的 `conversations.json` | 「导入 → 文件」，只取最终那条分支，被你重新生成掉的回答不要 |
| Claude.ai 导出的 json | 同上 |
| `.md` `.txt` `.tex` `.html` `.pdf` `.docx` | 「导入 → 文件」，可以一次拖多个 |

网页里用 KaTeX、MathJax 渲染过的公式，导入时会还原成 TeX 源码，不会变成一堆乱码。

## 能显示什么

- 公式：`$…$`、`$$…$$`、`\(…\)`、`\[…\]`、`\begin{align}…\end{align}`、```` ```math ````，化学式 `\ce{H2O}`
- 代码高亮、表格、引用、列表、图片、链接
- 流程图（```` ```mermaid ````）
- "价格是 $5 和 $10" 这种不会被误当成公式

显示用的库（KaTeX、markdown-it、highlight.js、mermaid、DOMPurify）都下载到了 `km/web/vendor/`，断网也能用。

## 安装和启动

需要 Python 3.11（FastNode 的 Python 包是给 3.11 编的）。

```bash
./setup.sh                   # 建虚拟环境，装 FastNode 和读 PDF / Word 的库
.venv/bin/python -m km --open
```

打开 http://127.0.0.1:8790/ 。数据存在 `data/km.db`，换个库用 `--db 路径`，换端口用 `--port`。只监听本机，别人连不上。

## 快捷键

| 键 | 作用 |
|---|---|
| `J` / `K`（或上下箭头） | 下一句 / 上一句 |
| `Y`（或空格） | 留下；再按一次取消 |
| `X` | 扔掉；再按一次取消 |
| `E` | 改这一句（`⌘↵` 保存，`Esc` 取消） |
| `M` | 跟上一句合并（拆错了的时候用） |
| `C` | 把这一句直接做成卡片 |
| `⌘↵` | 卡片编辑框里保存 |

你问的话不拆，整段保留，当作后面回答的上下文。

## 数据怎么存的

底层是 [FastNode](../Node)（同级目录 `Node`），一个 SQLite 上的节点库。三种节点：

```text
source  导入的一份资料            unit -in_source->  source
unit    拆出来的一句（或一块）    card -from_unit->  unit     （卡片来自哪几句）
card    一张知识卡片              card -<关系>->     card     （你连的关系）
```

- 删掉一份资料，它拆出的句子跟着删，**卡片保留**，只是"来自原文"那栏会空。
- 合并两句时，指向被合并那句的卡片会改指到合并后的句子，出处不会断。

## 测试

```bash
.venv/bin/python -m unittest discover -s tests -v
```

覆盖：拆句（中文、英文缩写、网址、小数、行内公式和代码不被拆、`$5` 不算公式、分号不拆）、整块不拆（公式、表格、代码、`\begin…\end`）、各种导入格式、存储（状态统计、合并后出处不断、关系增删、删资料卡片还在）、接口（报错是人话、只能读 `~/.claude/projects` 下的会话、静态文件不能越界读）。

## 还没做的

- 复习：卡片按间隔推给你考自己。
- 自动拆的粒度还要靠你用 `M` / `E` 修；以后可以让模型先给一版更好的切分，你只做取舍。
- 卡片之间的关系只能一条条连，还没有批量。
